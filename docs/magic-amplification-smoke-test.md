# 魔导增幅实机验收清单

本清单用于 `runClient` 本地世界。每一项都应在 JEI、控制器 GUI 和实际产出/耗能三处交叉确认。

## 1. 结构与仓室

1. 任取一台基础魔导机器（粉碎、化工、温室、爆炉）形成结构；分别只安装星辉透镜仓、只安装塔罗仓、同时安装两仓。
2. 验证机器保持原有能源、物品、流体、魔力/源质仓要求，新增仓室不会降低最低外壳数。
3. 工业天象观测阵列与天体校准矩阵：高级星辉透镜仓仍为必需，塔罗仓为可选；拆除塔罗仓不得导致机器失效。
4. 运行期间尝试抽取/更换晶圆和塔罗牌，确认槽位锁定；配方结束、取消或机器失效后确认解锁。

## 2. 星座与天空

1. 使用 `/pollutionmagic inspect` 检查主手星座数据晶圆的星座 NBT、昼夜和月相。
2. 使用 `/pollutionmagic profile magic_mixer` 检查机器的后备工序标签。
3. 在夜间天空可见时运行匹配配方，记录 GUI 中的基础强度与额外 +10%。
4. 以屋顶遮挡透镜仓、切换至白天或等星座不活跃后复测：基础强度保留，仅失去天空额外强度。
5. 使用高级透镜仓复测：基础强度应从 10% 变为 30%。

## 3. 配方与催化剂

1. 在 JEI 查看高阶魔法电路、星辉炼金、水晶催化、天象观测、天体校准配方；确认显示中文“魔导工序”和“可保护催化剂槽”。
2. 用带有催化剂保护的 UEV、OpV 或 MAX 魔法电路配方重复运行，记录星辉血魔催化剂/因果催化剂是否按星座和塔罗规则被返还。
3. 用不含 `CONSUMABLE_CATALYST_INPUTS` 的配方复测，确认普通材料不会被错误返还。

## 4. 特殊机器

1. 魔导电池：盾卫座检查容量、虚御座检查充放电上限；天空变化后确认已存 EU 不会丢失。
2. 大型、巨型魔导涡轮：满转子与非满转子各测试一次，确认发电倍率在原转子曲线之后生效，燃料与转子磨损逻辑不变。
3. 工业注魔：确认所有者研究校验仍有效，再验证透镜仓和塔罗仓只增加正向增幅。

## 5. 存档与边界

1. 配方运行中退出并重进世界，确认运行进度、战车累计、星星余韵、输出小数余量和锁定状态均正确恢复。
2. 满输出仓启动带安全额外产物的配方，确认机器不会因为扩容产物而丢失物品。
3. 同时满足多个增幅时，确认耗时、EU/t、魔法介质、产量、并行等均不超过系统上限。
